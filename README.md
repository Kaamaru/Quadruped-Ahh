# Quadruped 2-DOF Spider Robot

โปรเจกต์นี้เป็นหุ่นยนต์ 4 ขาที่ผมสร้างขึ้นเพื่อทดลองเกี่ยวกับการออกแบบหุ่นยนต์และระบบสมองกลฝังตัว โดยหุ่นยนต์ใช้ Servo Motor ทั้งหมด 8 ตัว แบ่งเป็นขาละ 2 ตัว เพื่อควบคุมการเคลื่อนไหวของแต่ละขา

ตัวหุ่นยนต์ใช้ ESP32 ในการควบคุมการทำงาน และใช้ PCA9685 สำหรับควบคุม Servo Motor นอกจากนี้ยังมีการนำเซนเซอร์ MPU6050 และ HMC5883L มาใช้ในการตรวจจับการเคลื่อนไหวและทิศทางของหุ่นยนต์

อีกส่วนหนึ่งของโปรเจกต์คือหน้าเว็บ HTML ใช้สำหรับปรับแต่งมุม Servo ทดลองท่าทางต่าง ๆ และสร้างรูปแบบการเดิน โดยสามารถบันทึกค่าที่ตั้งไว้เป็นไฟล์ JSON เพื่อนำกลับมาใช้งานได้

## 🛠 อุปกรณ์ที่ใช้

| อุปกรณ์ | หน้าที่ |
| :--- | :--- |
| **ESP32 (2 ตัว)** | ใช้ควบคุมตัวหุ่นยนต์และส่งคำสั่งแบบไร้สายผ่าน ESP-NOW |
| **PCA9685 (`0x40`)** | ใช้ควบคุม Servo Motor ทั้งหมดผ่าน I2C (SDA: GPIO 21, SCL: GPIO 22) |
| **MPU6050** | ใช้วัดความเร่งและการหมุนของตัวหุ่นยนต์ |
| **HMC5883L (`0x1E`)** | ใช้วัดทิศทางและสนามแม่เหล็ก |
| **LM2596 Buck Converter** | ใช้ลดแรงดันไฟจากแบตเตอรี่ให้เหมาะกับการจ่ายไฟให้ Servo (5–6V) |
