Calibration

Calibrate the board you are connected to (robot or controller, over its own USB).

1. Gyro

Put the board on a table and do not touch it for 2 seconds. The gyro is also calibrated automatically at every boot, so this is only needed if you moved the board while it started.

2. Compass

Keep the board away from servos, magnets and metal. Press Start, then slowly tumble the board through every orientation (like drawing a figure eight and turning it upside down) until the plots below become round circles around the centre and the check turns green. Then press Save: the offsets go into Settings and are used right away. Re-flash from the Prepare tab to keep them after a reboot.

Setup

Use one ESP32 on the robot, or two: the robot ESP32 plus a controller ESP32 that sends commands to it wirelessly (ESP-NOW). With two boards, use the switch to see each board's own wiring and code.

Both boards must use the same channel. To find a board's MAC: flash its code, press Connect WebSerial, and use the button in the popup. Leave the controller MAC at 00:00:… to let the robot accept any sender. These values go into both codes; re-flash after changing them.

⚠ The robot MAC is still 00:00:00:00:00:00. The controller cannot reach the robot until you enter it.
⚠ External servo power required Servos can draw 500mA to 2A each under load. Do NOT power multiple servos from the 5V pin of an Arduino or ESP32. Connect a dedicated 5V/6V supply (3A–5A minimum) to the PCA9685 V+ screw terminal and join all grounds together.

Robot ESP32 firmware

Put each firmware in its own sketch folder (for example robot/robot.ino). Arduino compiles every .ino file in a folder together, so two firmwares or an old sketch in the same folder cause “redefinition” errors.

Load & safety

    
For a heavy robot. The robot moves all servos of a pose together on a smooth curve and never faster than the speed limit. With feedback wires it also detects an overloaded servo, holds it instead of forcing it, slows everything down and retries. These values are written into the robot code (Prepare tab).
